# Ball-Drop
Ball Drop: free 3D hyper-casual ball game like Stack Ball and Helix Jump. Hold to smash spinning plates, steer the tower, dodge black blocks and chain 15 plates for a fire boost. 50,000 stages, 170+ plate shapes, 11 ball skins, weather skies, calm music, offline, no ads. One-touch Android APK and browser game. Created by Fayyaz Rajpoot.
